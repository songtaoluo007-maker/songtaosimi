# 本地私人基金分析落地说明

## 每日自动流程

系统启动后会注册定时任务，默认在每个交易日 14:30 生成尾盘持仓建议。生成前会依次刷新：

1. A股主要指数
2. 行业板块行情
3. 当前持仓基金盘中估值
4. 财经新闻和持仓相关资讯
5. 持仓盈亏
6. AI结构化建议

建议结果会保存到本地 SQLite 数据库，不上传你的持仓数据到除已配置 AI 接口之外的其他服务。

## 关键配置

在项目根目录 `.env` 中调整：

```env
AI_ADVICE_HOUR=14
AI_ADVICE_MINUTE=30
AI_ADVICE_PRE_REFRESH=true
AI_NEWS_LOOKBACK_DAYS=3
```

`AI_ADVICE_PRE_REFRESH=true` 表示每次生成建议前先刷新行情、估值和新闻，适合尾盘决策。若只想基于已有本地数据复盘，可改为 `false`。

## 使用建议

- 保持系统在交易日 14:30 前已经启动，否则定时任务不会执行。
- 持仓数据越完整，建议越可靠；至少应录入基金代码、份额、成本和当前市值。
- 新闻情绪只是轻量关键词标注，AI 会结合标题、行情和持仓一起判断。
- AI 建议应作为个人辅助决策和复盘材料，最终交易仍需你确认。

## 本地产品化标准

- 数据可追溯：每条建议保存生成时间、行情时间、估值时间、新闻数量和模型消耗。
- 决策可执行：每只基金输出 `add/reduce/hold`、建议比例、置信度和原因。
- 风险可见：每条建议输出市场观点和风险等级。
- 可手动兜底：系统设置页可查看调度任务，也可以手动触发尾盘建议。
